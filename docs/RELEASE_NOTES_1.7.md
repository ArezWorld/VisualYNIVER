# AOT 1.7.x Stable Release Notes

## Что вошло
- Переведён канал релизов на стабильные версии `1.7.x` (без pre-release).
- Сборка в GitHub Actions переведена на `assembleRelease`.
- APK публикуется в формате `AOT-1.7.X.apk`.
- Проведена чистка `MapFragment`: удалён мёртвый код префетча тайлов.
- Оптимизировано отображение POI: оставлены только приоритетные категории (Магнит, Пятёрочка, банк, МИСИС).
- Выровнены размеры значков и отдельно увеличены иконки банка и МИСИС.

## Чек-лист перед релизом (выполнено)
- `clean`
- `assembleDebug`
- `assembleRelease`
- `testDebugUnitTest`
- `lintDebug`

## Известные ограничения
- После очень резкого и многократного zoom in/out иконки POI могут появляться с короткой задержкой.
- Если отчёт `.docx` открыт в Word, скрипт генерации не сможет перезаписать файл до его закрытия.
